Veterinary Ophthalmology Research Agent

Veterinary Ophthalmology Research Agent is a private, owner-operated research workflow. It identifies NCBI/PubMed literature alert emails in the owner's Gmail account, extracts PubMed identifiers, and uses those identifiers to support veterinary ophthalmology literature review.

This application is not offered as a public service. Only the owner, or an account explicitly authorized by the owner, may use it.

Google data access

The application requests read-only Gmail access. It searches for NCBI/PubMed alert messages and reads their content only to identify relevant PubMed records. It does not send, delete, modify, label, archive, or mark Gmail messages as read.

Data handling

Gmail data is processed locally for this research workflow. The application stores limited alert metadata and extracted PubMed identifiers; it does not retain the raw email body. For full details, see the privacy policy.
